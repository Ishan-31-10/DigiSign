# Deployment Guide

Use this setup:

- Frontend: Vercel
- Backend: Render using `render.yaml`
- Database: MongoDB Atlas

Do not deploy MongoDB from `docker-compose.yml` to production. Docker Compose is only for local testing.

## 1. MongoDB Atlas

Create a MongoDB Atlas cluster, then copy the driver connection string.

It should look like:

```env
mongodb+srv://USERNAME:PASSWORD@cluster0.xxxxx.mongodb.net/digsign?retryWrites=true&w=majority
```

In Atlas, open **Network Access** and allow your backend host. For quick testing you can use `0.0.0.0/0`, then restrict it later.

## 2. Backend on Render

1. Push this repo to GitHub.
2. In Render, choose **New +** -> **Blueprint**.
3. Select this repository.
4. Render will read `render.yaml`.
5. Add these environment values when Render asks:

```env
MONGODB_URI=mongodb+srv://USERNAME:PASSWORD@cluster0.xxxxx.mongodb.net/digsign?retryWrites=true&w=majority
CORS_ORIGIN=https://your-vercel-app.vercel.app
FRONTEND_URL=https://your-vercel-app.vercel.app
```

`JWT_SECRET` is generated by Render from `render.yaml`. You can also set your own long random value.

After backend deploys, test:

```text
https://digisign-pbcb.onrender.com//api/health
```

Seed users from Render Shell:

```bash
npm run seed
```

## 3. Frontend on Vercel

1. In Vercel, import the same GitHub repo.
2. Set **Root Directory** to:

```text
frontend
```

3. Add this environment variable:

```env
NEXT_PUBLIC_API_URL=https://digisign-pbcb.onrender.com/api
```

4. Deploy.

After Vercel gives you a URL, go back to Render and update:

```env
CORS_ORIGIN=https://your-vercel-app.vercel.app
FRONTEND_URL=https://your-vercel-app.vercel.app
```

Then redeploy the backend.

## 4. Local Docker

For local Docker, use root `.env`:

```env
JWT_SECRET=replace-with-a-long-random-secret
JWT_EXPIRES_IN=7d
MONGODB_URI=mongodb://mongo:27017/digsign
CORS_ORIGIN=http://localhost:3000
FRONTEND_URL=http://localhost:3000
NEXT_PUBLIC_API_URL=https://digisign-pbcb.onrender.com/api
MAX_FILE_SIZE_MB=25
```

Run:

```bash
docker compose --profile local-db up --build
docker compose exec backend npm run seed
```

Do not run `docker compose down -v` unless you want to delete local MongoDB data.
